Focus ring

Button Coding
2 pt accent outline, 2 pt offset, same corner radius as the control plus the offset. Keyboard focus only; clicks never show it. In Increase Contrast the ring becomes 3 pt and white on dark, black on light.
NativeAll of these are ButtonStyle, ToggleStyle and LabelStyle over system controls, so keyboard navigation, VoiceOver and Dynamic Type come free. Glass is glassEffect(_:in:); the focus ring is the system focusEffect tinted with the accent.
