Type
Numerals scale to 130 %; the medium widgets drop the sub-line first.
NativeWidgetKit: systemSmall, systemMedium, systemLarge. Static widgets refresh with a TimelineProvider on the hour and after each landing. The live widget uses Text(timerInterval:) so the countdown ticks without any updates, and a Button(intent: PauseFlightIntent()) for Pause.
Tinted and clearFor the macOS Tahoe tinted and clear widget styles the ring, bars and route get .widgetAccentable(); everything else renders in the system label color. Backgrounds use containerBackground(for: .widget) with the glass material.
