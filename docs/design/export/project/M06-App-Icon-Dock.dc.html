NativeThe icon is an Icon Composer document (.icon) with a background group and a glyph group, so macOS can render Default, Dark, Tinted and Clear itself and add the Liquid Glass specular edge. Layer names: bg, globe, trail, plane (A), pass, notch, bars (B), wall, window, sky, shade (C).
Dock tileNSApplication.dockTile.contentView = SwiftUI view with a Circle().trim ring (3.5 pt, 5 pt gap) and a time pill; updated by a 1 s timer only while in flight. Badge via dockTile.badgeLabel, count of unanswered flight invites. One bounce on boarding call, never repeating.
