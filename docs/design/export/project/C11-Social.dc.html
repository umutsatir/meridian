Public departures board

{{b.n}} aboard
Departures · hover row highlighted
Rows are public flights anyone can join, sorted by departure. The status cell flips when it changes: BOARDING IN 06:12, BOARDING, DEPARTED. A row is a button; Return joins the lobby. Names are never shown, only the number aboard.
NativeThe board is a LazyVStack of rows; each cell is a Canvas with a Metal flap shader, flipping through the alphabet like a real split-flap. Presence uses TimelineView; strips use matchedGeometryEffect to animate a passenger into the map.
