# Audio credits and licensing

## Boarding / landing chime (the airport "ding-dong")

**Source: synthesized in code, no third-party recording** (`MRCueRenderer.chime`, `paBell`). Nothing to attribute.

- Boarding: two soft bell notes, E5 (659.25 Hz) then C5 (523.25 Hz) 0.52 s apart. Landing: a single E5 "ding".
- Bell partials 1 / 2.76 / 5.4, 25 ms swell, light room send. Rendered once offline (about 2.5 s for boarding, under 3 s).

A real recording was searched for and **not used** because its licence could not be trusted:

- Openverse API (`api.openverse.org`): unreachable from the build machine (timeouts), so it could not be searched.
- Wikimedia Commons: the only hit was `File:Airplane Chime Sound Effect.opus` (tagged "Public domain / PD-ineligible"). It was uploaded
  from a YouTube video ("Airplane Ding Dong Sound Effect") of unknown origin, the author field names an ARINC specification rather than a
  person, and the file is still marked `LicenseReview`. The PD claim rests on the tone being too simple to be copyrightable, which is
  not a clear licence for commercial use, so it was left out.

### Dropping in a real recording

If a recording with a clear licence (CC0 / public domain / own work) is found, put it in the app bundle as

- `Announcements/boarding-chime.(caf|m4a|wav|mp3)` for the boarding chime,
- `Announcements/landing-chime.(caf|m4a|wav|mp3)` for the landing chime (optional).

`AnnouncementLibrary.chimeFile(_:)` picks it up automatically; otherwise the synthesized bell plays. Files are converted to the engine
format, truncated to 3 s, peak-limited to 0.9 and given 5 ms / 250 ms edges. Record the source, author and licence in this file when you add one.

## Everything else

All other cues and ambient layers are generated by `MRCueRenderer` / `MRAmbientDSP` from the recipes in `meridian-audio.js`. No samples are bundled.
